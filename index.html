Important: MyCapital is a personal record-keeping prototype. It is not connected to a bank or investment provider and cannot move or invest money. Your records remain in this browser on this device. Prototype 1.7 keeps the same saved-record storage keys as Prototype 1.6, so it can continue using your existing 1.6 records. It does not automatically import Prototype 1.5 records. Browser storage is not encrypted by this prototype. Export backups regularly and keep backup text private.
